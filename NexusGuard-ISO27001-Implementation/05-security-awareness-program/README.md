# Security Awareness Program FY2026

Fictional role-based security awareness program for 450 staff: program plan, 12-month calendar with KPI targets, and a 15-slide phishing training module, mapped to ISO 27001 A.6.3, HIPAA and PCI DSS 12.6.

## What this project is

The people layer of the ISMS. A phishing simulation found that **34%** of staff clicked and **18%** entered credentials, and the last training was 22 months old. The program designs role-based training for four audiences (320 general staff, 65 IT staff, 35 managers and executives, 30 customer-facing staff), a measurement framework, and a 12-month campaign calendar.

## Targets at a glance

| Measure | Baseline | December target |
|---|---|---|
| Phishing click rate | 34% | 5% |
| Credential entry rate | 18% | 1% |
| Report rate | Not measured | 70% |
| Training completed on time | No program | 98% |

## How it supports ISO/IEC 27001:2022

| Requirement | Where it is addressed |
|---|---|
| A.6.3 Information security awareness, education and training | Plan, tracks and calendar |
| Clause 7.3 Awareness | Role-based content and campaigns |
| A.6.8 Information security event reporting | Reporting habit built into simulations and module |
| Clause 9.1 Monitoring and measurement | KPI framework and tracker |

HIPAA 164.308(a)(5) and PCI DSS Requirement 12.6 are mapped in the plan.

## What this project demonstrates

- Designing role-based training from an audience and threat analysis
- Setting KPIs with baselines, targets and RAG rules
- Running a supportive, not punitive, phishing simulation program
- Building engaging training content with interactive exercises and a knowledge check
