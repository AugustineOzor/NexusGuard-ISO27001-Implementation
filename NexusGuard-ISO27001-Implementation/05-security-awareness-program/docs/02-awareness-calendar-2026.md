# NexusGuard Security Awareness Calendar, FY2026

Markdown view of `NexusGuard_Awareness_Calendar_2026.xlsx`. One theme per month; core modules (GS) go to all 450 staff, and specialist modules go to the IT, Management and Customer-facing tracks. Phishing simulation rounds run every second month.
