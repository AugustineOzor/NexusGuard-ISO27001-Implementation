# ISMS Governance, Risk and Metrics

Fictional ISO 27001 governance toolkit: ISSC, Risk and Compliance committee charters, board and ISSC report templates, a 26-metric GRC KPI framework with baseline narrative and Excel dashboard, and a 42-activity RACI matrix.

## What this project is

The management layer of an ISO/IEC 27001:2022 ISMS. It answers the CEO's question, "How will we know if our security program is actually working?" by setting up the committees that govern security, assigning accountability for 42 security activities, and building the metrics and reports that show results to management and the Board.

## How it supports ISO/IEC 27001:2022

| Requirement | Where it is addressed |
|---|---|
| Clause 5.1 Leadership and commitment; 5.3 Roles and authorities | Charters and RACI |
| Clause 6.2 Information security objectives | Metrics framework |
| Clause 9.1 Monitoring and measurement | KPI framework, dashboard and narrative |
| Clause 9.3 Management review | Monthly ISSC and quarterly Board reports |
| A.5.2 Information security roles and responsibilities | RACI matrix |
| A.5.4 Management responsibilities | Charters and decision rights |

## What this project demonstrates

- Designing governance bodies with real decision rights and escalation limits
- Building a measurable metrics framework with baselines, targets and thresholds
- Reporting at the right level for the steering committee and the Board
- Assigning clear accountability, and finding gaps and overlaps

## Scenario note

The exercises in this series used slightly different NexusGuard details in places (for example offices and headcount), so each document reflects the facts of its own scenario.
